# 注册路径咨询

## 触发条件

用户已经明确说出了类别（「我们是二类」「三类产品」），或者上一轮已判定出类别。
这时不需要重新检索分类目录，直接走规则表。

## 回答结构

```
办理方式：注册
受理机关：省级药品监督管理部门
临床评价：需核对是否在《免于临床评价医疗器械目录》内
依据：class_rules[Ⅱ]
```

## 三类的差异要点

| 类别 | 办理 | 受理 | 特点 |
|---|---|---|---|
| Ⅰ | 备案 | 市级 | 材料最简，一般免临床 |
| Ⅱ | 注册 | 省级 | 需检测报告，临床评价看目录 |
| Ⅲ | 注册 | 国家局 | 通常需临床评价，周期最长 |

## 注意

- Ⅰ 类说的是「备案」不是「注册」，说错是很外行的话
- 临床评价和「临床试验」不是一回事，不要混用
- 具体材料清单以当地药监最新要求为准，知识库未收录，要明确说「需核对官方办事指南」
