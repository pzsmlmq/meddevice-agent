# 多跳判定

## 四跳

```
第1跳  产品描述  →  候选类别（classify_product）
第2跳  候选类别  →  注册路径（registration_path）
第3跳  注册路径  →  临床评价（clinical_eval_required）
第4跳  汇总      →  结论 + 依据
```

每一跳的输入必须是上一跳的输出，不许跳步。特别是第 2 跳——不许自己「感觉」它是二类。

## 置信度怎么处理

`classify_product` 返回置信度，按这个规则走：

| 置信度 | 动作 |
|---|---|
| 高 | 走完四跳，给完整结论 |
| 中 | 走完四跳，但结论里标注「建议核对原文」 |
| 低 | **停在第 1 跳**，列候选，追问关键信息，不要算路径 |

第三行是最重要的。低置信度还算路径，等于把错误放大三遍。

## 输出格式

```
结论：Ⅱ类，注册，省级药监受理，临床评价需核对免临床目录

依据：
- 记录 176 · 09内窥镜用组织钳 · Ⅱ类 · 《医疗器械分类目录》…
- 记录 177 · 10内窥镜用取样钳 · Ⅱ类 · 同上

不确定的地方：
- 是否一次性无菌未说明，若为可重复使用，可能影响临床评价要求
```

## 注意

Ⅱ 类的临床评价结论只能是「需核对目录」。知识库里没有《免于临床评价医疗器械目录》原文，
不许说「可以免临床」——那是在编。
