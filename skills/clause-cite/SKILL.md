# 取证与引用

## 什么时候用

已经定位到某条记录，需要在回答中引用它；或者需要核对记录原文是否真的支持某个结论。

## 步骤

1. 用 `get_concept(record_no)` 取完整条目：产品描述、预期用途、品名举例、管理类别
2. 用 `get_clause(record_no)` 取法规出处
3. 核对：这条记录的**预期用途**是否覆盖用户描述的场景

第 3 步是最容易偷懒的一步，也是唯一有价值的一步。编号对上不等于场景对上。

## 引用的格式

固定三要素，缺一不可：

```
记录 176 · 09内窥镜用组织钳 · 《医疗器械分类目录》02无源手术器械 / 手术器械-钳
```

- 编号：用于用户回查
- 名称：用于人读
- 出处：用于核对

## 不许做的事

- 不许改写原文措辞后当作引用
- 不许引用没取过的记录（哪怕是「大概第 200 条」）
- 依据为空时说「该条目无单独法规出处，依据为目录本身」，不要编一个文号
